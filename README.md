# 🏥 AI Healthcare Assistant

An AI-powered Disease Prediction and Medicine Recommendation System developed using Machine Learning and Flask.

## 📌 Overview

The AI Healthcare Assistant predicts diseases based on patient health information and recommends suitable medicines from a healthcare database. The system provides a user-friendly web interface and generates downloadable patient reports.

## 🚀 Features

- Disease Prediction using Machine Learning
- Medicine Recommendation System
- Health Tips for Patients
- PDF Report Generation
- Modern Responsive User Interface
- Flask-based Web Application
- Real-Time Prediction Results

## 🛠 Technologies Used

- Python
- Flask
- Scikit-Learn
- Pandas
- HTML5
- CSS3
- Machine Learning

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Jananii-Vijaykumar/AI-Healthcare-Assistant.git
cd AI-Healthcare-Assistant
```

### Install Dependencies

```bash
pip install flask pandas scikit-learn joblib
```

### Run Application

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```

## 🎯 Workflow

1. Enter patient details.
2. Click Predict Disease.
3. Machine Learning model predicts disease.
4. Recommended medicines are displayed.
5. Health tips are provided.
6. Patient report can be downloaded.
